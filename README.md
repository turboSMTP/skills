# turboSMTP skills

Planning home for official turboSMTP Agent Skills.

**Status: planning.** The repository currently contains the scope and publication plan. Installable skills, release assets and plugins have not been published.

Read [PLAN.md](PLAN.md) for the proposed four-skill launch, task boundaries, evaluation cases, private pilot and public release process.

The planned skills help agents integrate turboSMTP into applications, authenticate sending domains, investigate delivery and send an explicitly requested email. They complement the [turboSMTP MCP server](https://github.com/turboSMTP/mcp) and the [developer documentation](https://serversmtp.com/docs).

The repository remains private during preparation. Installation commands in the plan describe future releases and will not work until those skills exist.
